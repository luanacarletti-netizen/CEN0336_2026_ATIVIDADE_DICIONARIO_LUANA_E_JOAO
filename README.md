# Atividade – Dicionários em Python

Este projeto utiliza um dicionário em Python para registrar causas de condenação encontradas durante a inspeção post mortem de bovinos.

As chaves representam as causas de condenação e os valores representam a quantidade de ocorrências.

O código demonstra as operações de acesso, inserção, atualização, `.get()` e `.items()`.

## Como executar

Com o Python 3, execute no terminal:

python condenacoes_bovinos.py
